# ☦ Православен календар 2026

Интерактивен православен календар на **български език** с постите, празниците, светците и избрани именни дни за всеки ден през 2026 г.

## Съдържание
- `index.html` — начална страница и изглед на календара
- `styles.css` — адаптивен дизайн за телефон и компютър
- `app.js` — навигация по месеци, търсене, подробности за ден
- `data/pravoslaven-kalendar-2026.json` — 365 дневни записа в JSON
- `docs/IZTOCHNICI.md` — източници и ограничения на данните

## Стартиране
Няма нужда от npm, React или сървърно приложение. Използвайте статичен HTTP сървър (например `python3 -m http.server 8000`) или GitHub Pages. Отварянето направо през `file://` може да блокира зареждането на JSON поради ограниченията на браузъра.

### GitHub Pages
В GitHub: **Settings → Pages → Deploy from a branch → main / (root)**. Този проект може да работи като статичен уебсайт.

## Данни и точност
Пасха за 2026 г.: **12 април**. Данните обхващат **01.01–31.12.2026**.

**Това е неофициална работна база**, а не заверено издание на Българската православна църква. Част от житийните описания са общи, а някои типикални разрешения за постене трябва да се сверят с официалния годишен календар и духовник. Вижте [източниците и поясненията](docs/IZTOCHNICI.md).

Официален календар: https://bg-patriarshia.bg/calendar/2026
